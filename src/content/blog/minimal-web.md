Most web applications ship hundreds of kilobytes of client-side JavaScript before rendering a single word of text.

### The philosophy

1. Use semantic HTML elements.
2. Rely on modern CSS variables and layouts.
3. Deliver pre-rendered static markup.
4. Add zero client-side scripts unless strictly required.
